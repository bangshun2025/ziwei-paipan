## 一、概述

本文档是紫微斗数排盘项目的**全量测评手册**：固化自动化断言资产、分层说明覆盖口径、给出每轮回归的统一执行命令。任何版本（实现/修复/重构）合入前，必须跑完本手册所列回归，全部通过才允许进入发布流程。

自动化资产总览：

| 组 | 命令 | 断言数 | 基准 | 何时必跑 |
|----|------|:------:|------|----------|
| L1 锚点回归 | `node tests/run_anchor_tests.js` | 1242 | iztro 12 盘全字段快照 | 任何算法/常量改动 |
| L2 cases 定向 | `node tests/run_case_tests.js` | 45 | 口径差异 + 定向断言 | 历法/边界/展示层改动 |
| L3 内嵌自检 | 浏览器 `index.html?test=1` | 88 | 常量/历法/安星/端到端 | 每轮发布前人工红线 |

> **82 vs 88 口径说明**：v0.1.0 验收期 QA 报告、check-release.sh 注释曾记「82 条」（修复前静态计数）；验收定稿按**运行时实际执行 = 88 条**（L3 自检含循环展开，浏览器实测 88/88 ALL PASS）。本手册以 88 为权威口径，check-release.sh 注释同步修订。

## 三、测试分层体系

```
L1 算法验证层（node CLI · 1242）   ← iztro 权威锚点整盘比对，回归主力
L2 定向差异层（node CLI · 45）     ← 口径差异/边界/展示层定向断言
L3 内嵌自检层（浏览器 · 88）       ← 常量/历法/安星/端到端快速体检
L4 人工冒烟项（发布师/用户）       ← UI 点击流 + 文墨天机抽核（观察级）
```

执行顺序：L3（秒级体检）→ L1 + L2（node 全量）→ L4（发布前人工）。

## 八、回归执行手册

```bash
# 1. 发布前一致性校验（版本/语法/结构/引用）
bash scripts/check-release.sh

# 2. L1 锚点全字段回归（1242 断言）
node tests/run_anchor_tests.js          # 期望 ALL PASS ✅ / 退出码 0

# 3. L2 cases 定向（45 断言）
node tests/run_case_tests.js            # 期望 ALL PASS ✅ / 退出码 0

# 4. L3 内嵌自检（88 断言）
# 浏览器打开 index.html?test=1 → ALL PASS ✅（人工红线，发布师必查）

# 5. （发布前）线上发布脚本 dry-run
bash scripts/publish-online.sh         # 前置检查全绿后再 --exec
```

**回归触发规则**：
- 改 constants.js / algorithm.js → 必跑 L1 + L2 + L3
- 改 render.js / main.js（展示层）→ 必跑 L2 + L3（视改动范围补 L1）
- 改历法表/口径 → 全量 L1 + L2 + L3
- 每轮发布前 → check-release.sh + L1 + L2 + L3
