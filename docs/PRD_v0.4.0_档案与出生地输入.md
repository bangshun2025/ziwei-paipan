# PRD v0.4.0 — 档案功能与出生地省市区输入

- 版本：v0.4.0（基线：v0.3.0-ref 收口 66c7f4c）
- 日期：2026-09-06
- 需求来源：用户 2026-09-06 第1轮「紫微斗数是和命理有关的，要加档案功能，参考八字排盘；出生年月日及真太阳时整套借鉴过来，放到原位置」。第2轮方案3拍板：**补姓名输入 + 📋档案功能（本地存/载/编辑/删/搜索/回收站），出生地升级为省市区三级联动并实时显示真太阳时（不改时辰 chips）**。

## 1. 背景与目标

紫微斗数排盘当前为「单次排盘即弃」：输入面板无姓名、无档案，出生地仅有 15 城市+自定义经度下拉，真太阳时仅在校验开启时静默作用于排盘，用户无感知。

借鉴对象：八字排盘（软件-八字排盘·运行）已实现成熟的输入体系与档案功能：
- 姓名（inName）+ 性别 + 新历/农历 + 年月日 + 闰月 + 时分 + 出生地省市区三级联动 + liveSolar 实时真太阳时显示；
- 📋档案：localStorage 本地档案（保存/载入/编辑/删除/搜索/回收站/隐私模式），archive.js 约 916 行，另有云端分支（本次不借鉴）。

目标：紫微 v0.4.0 补齐「姓名 + 出生地省市区 + 实时真太阳时 + 本地档案」，让命主信息可留存、可复现、可检索；同时不改变紫微特有的「时辰 chips」输入范式与排盘口径。

## 3. 功能范围（v0.4.0 采纳口径）

### A. 姓名输入
输入面板新增姓名行（第一行，历法行之前）：label「姓名」+ input#inName（text，placeholder「请输入姓名（用于档案标识）」）。
- 姓名仅作档案标识与显示，不参与排盘算法；
- 为空时排盘/存档不阻断，档案条目显示「未命名」。

### B. 出生地省市区三级联动 + 实时真太阳时
出生地由「城市下拉+自定义经度」升级为「省 → 市 → 区县」三级联动：
- 省下拉 #fProv（LOC_DATA 34 省 + 首项「— 未选择（按北京时间120°E）—」）；
- 市下拉 #fCity（随省联动；市值携带经度）；
- 区县下拉 #fDist（随市联动，仅行政细分，不影响经度）；
- 自定义经度保留：#fProv 末项「自定义经度…」→ 显示 #fLng 手输框（73-136）；也可在已选省市下手动覆写 #fLng 微调经度；
- 经度回填规则：选市 → #fLng 自动填该市 lng（可手改）；选省未选市 → 不填；三级均未选 → 空（按北京时间）。
- **不改时辰 chips**：不引入时分输入，出生时辰仍用 chips。
- **liveSolar 实时显示**：真太阳时校正行内新增只读文本 #liveSolar（样式浅色小字，位于 fTrueSolar 之后）：
  - 显示「真太阳时 HH:MM（经度偏移 +X 分钟，均时差 Y 分钟）」；
  - 计算基准 = 当前选中 chip 代表时刻（SHICHEN h:mi，时辰中点）+ 当日均时差 + 经度偏移（复用 algorithm.js equationOfTime/trueSolarTime）；
  - 若校正结果跨入相邻时辰段，追加提示「≈X时（已跨入卯时段）」；
  -   任何输入变化（日期/时辰 chip/省市/经度/开关）实时刷新；未选经度时不显示或显示「未校正（120°E）」。

### C. 📋档案功能（本地 localStorage，借鉴八字 archive.js 本地主干）
入口：输入面板操作行「开始排盘」左侧新增按钮「📋档案」（#btnArchive），打开档案弹层面板（#archivePanel，遮罩+卡片式，同页内 div 显隐，不引依赖）。

功能清单：
1. **列表展示**：卡片列表按更新时间倒序，每张卡片显示：姓名（无则「未命名」）+ 性别徽标 + 历法/日期 + 时辰 + 出生地（省市 或 自定义经度）摘要 + 更新时间。空态文案「暂无档案，先排一次盘再保存」。
2. **保存当前输入**：面板顶部「+ 保存当前输入」按钮 → 读取表单快照生成档案（id=时间戳随机串），重名不合并，直接追加；保存后 toast「已保存」并刷新列表。
3. **载入**：点卡片「载入排盘」→ 档案字段回填表单（含历法 mode 切换、闰月、chip 高亮、性别、省市县三级、经度、真太阳时开关、晚子时口径）→ 关闭面板 → doCalc() 自动排盘并滚到结果。
4. **编辑**：卡片「编辑」→ 弹内联编辑面板（#archiveEditPanel），字段=姓名 + 性别 + 历法/日期/闰月 + 时辰 chips + 省市县 + 经度 + 真太阳时 + 备注（多行）→ 保存写回（updatedAt 刷新）。与载入共用同一套回填/读取函数。
5. **删除与回收站**：卡片「删除」→ 移入回收站（软删，localStorage 双键：档案主键 + 回收站键）；主面板底部「回收站」入口 → 回收站面板：列表 + 「还原」/「彻底删除」/「清空回收站」。
6. **搜索**：面板顶部搜索框 #archiveSearch，按姓名/备注/日期 关键字实时过滤列表。
7. **数据上限**：主档案上限 200 条，超出时拒绝保存并提示清理；每次读写 try/catch，localStorage 满（QuotaExceededError）提示导出清理。

### D. 档案数据模型（紫微专属字段，含算法复现所需全量口径）
每条档案 = 一次完整排盘输入快照，保证「载入 → 复现同一张盘」：
```
{ id, name, gender(M/F), mode(solar/lunar), y, m, d, leap(闰月bool),
  scIdx(chip 下标，与 h/mi 冗余，载入用下标高亮 chip),
  h, mi, prov, city, dist, lng, useSolar(bool),
  advLateZi(forward/current 晚子时口径), note, createdAt, updatedAt }
```
存储键（独立前缀，避免与八字同域冲突）：
- 主档案：`zw_arch_v1`
- 回收站：`zw_trash_v1`
- （八字为 ARCH_KEY/TRASH_KEY 通用名，紫微必须加 zw_ 前缀）

### E. 模块与数据落位
- 省市区数据：从八字 index.html 885-1263 行复制 LOC_DATA，落为 **新文件 js/locdata.js**（IIFE，挂 window.LOC_DATA），index.html 在 constants.js 之后、algorithm.js 之前引入（改动 `?v=330` 缓存戳 → 331）；
- 档案逻辑：**新文件 js/archive.js**（IIFE，挂 window.ARCHIVE），含存储/CRUD/回填/读取/搜索/回收站/编辑面板渲染（参照八字 archive.js 本地主干，去云端/隐私分支）；
- main.js：state 扩展 name/prov/city/dist/scIdx；initApp 接线（inName/fProv/fCity/fDist/#liveSolar/#btnArchive/面板开关）；doCalc 无算法改动（getChart 入参不变）。

## 4. 边界与不做什么（v0.4.0 明确不做）
- 云端同步 / 登录体系（八字 Supabase 分支）不做；
- 隐私模式（列表脱敏显示）不做（本地工具，后续视需要加）；
- 时分输入不引入（保持时辰 chips 范式）；
- 不改任何排盘算法/口径/渲染（纯输入与存储层）；锚点 1242 + cases45 必须原样回归；
- 农历模式下档案「载入后跨公/农历换算」仅回填原字段，不二次换算；
- 不做档案导出/导入文件。

## 5. 验收标准（AC）
- AC1 输入面板出现姓名行；空姓名排盘不报错，档案显示「未命名」。
- AC2 出生地三级联动：选省 → 市列表刷新；选市 → 区县刷新且 #fLng 回填市级经度；选「自定义经度…」→ 手输框出现；三级清空 → lng 空。
- AC3 liveSolar：默认示例（2000-8-16 寅时、未选地）显示 120°E 未校正提示；选「北京」后文本实时变化且数值 = algorithm.trueSolarTime 同参输出（抽查 3 组）；跨时段 chip 时出现「已跨入」提示；开关关闭后不再显示偏移（或显示未校正）。
- AC4 保存：点击「保存当前输入」生成卡片；localStorage zw_arch_v1 条数 +1；刷新页面后仍在。
- AC5 载入复现：保存默认示例 → 改动表单（换日/换 chip/换地）→ 载入该档案 → 表单逐字段还原 + 自动重排；两次排盘 chart 输入快照一致（对比 window.__CHART__.input 关键字段）。
- AC6 编辑：改姓名+备注保存后卡片与存储同步更新；编辑面板改日期后 updatedAt 变化。
- AC7 删除/回收站：删除后主列表消失、zw_trash_v1 +1；还原回主列表；彻底删除/清空后两键均无。
- AC8 搜索：按姓名关键字过滤命中；按备注关键字命中；无命中显示空态文案。
- AC9 回归：自检 ?test=1 全绿（原 88 断言 + 新增档案用例）；锚点 1242 全等；cases 45 全过；check-release.sh 通过（版本线 v0.4.0 同步）。
- AC10 缓存戳：index.html 引入 ?v=331；不残留 v=330 引用。

## 6. 风险与注意
- localStorage 与八字同域共用：键名必须 zw_ 前缀（已在 D 约束）；
- 真太阳时跨时段提示仅信息性，**不自动改 chip**（用户拍板口径）；
- LOC_DATA 27.5K 全量复制会使仓库 +~28KB，可接受；后续如需瘦身可裁剪区县；
- 版本线：constants.js 内部 VERSION='v0.1.0' 与头部 v0.3.0-ref 不一致的历史债，本次发布时一并对齐 v0.4.0（check-release.sh 的 version_of 取首个 vX.Y.Z 会命中内部 VERSION，需确认对齐策略）。
