> 状态：实现中 ｜ 基线：v0.4.0（tag v0.4.0-ref） ｜ 关联：PRD_v0.4.0 §D（档案字段模型）

## A. 背景

用户比对八字排盘输入模块，指出紫微输入缺三类能力，要求「完全仿照八字排盘」补齐：
名字（小名/艺名/姓名）、AI 自然语言录入、隐私功能。性别/新农历生日切换/真太阳时+省市区/档案 紫微 v0.4.0 已有且部分更强（默认真太阳时、三级联动+自定义经度、实时显示），本轮不改结构，只对齐缺项。

## C. 设计口径

### C1. AI 自然语言录入（仿八字 parseNaturalInput）
- 弹窗入口：输入区按钮 `🤖 AI 录入`；textarea + 实时预览 + 「解析并填入」
- 解析序：性别（男/女）→ 中文日期 `yyyy年m月d日`（闰月 `年闰?m月`，leap 标记）→ 数字日期 `yyyy-m-d|.`|`/` → 农历标记词（农历/阴历/旧历/老历，含括号写法）→ 时间（修饰词 12 时制偏移：凌晨/早上…；`早子时|晚子时|X时` 时辰词直读 SHICHEN；`5点|5:01|5时01分`）→ 省市区（LOC_DATA 长度降序 + 短名去尾缀 [省市区/市县区/县区市] 匹配原始文本）→ 姓名（剩余 2-4 连续汉字）
- 预览：姓名（隐私开显示「已隐藏」）· 性别 · 年月日（历法标注）· 时:分 · 省市县
- 填入：切历法 → 填日期/闰月 → 性别（男/女→M/F）→ 时辰（scIdxOf 折算高亮 chip）→ 姓名 → 省市区同步联动 + 经度回填 → doCalc
- 校验：缺日期 → 提示「未能识别完整日期」不填入

### C2. 隐私模式（仿八字 v0.19.0）
- 全局开关 `zw_privacy`（localStorage；缺省=开启），按钮 `🔒 隐私`/`🔓 隐私`（输入区 + 档案面板头两处同步）
- 显示名口径 `getDisplayName(s)`：
  - 隐私关：有小名 → `小名 / 正名`；无小名 → 正名
  - 隐私开：艺名 → 小名 → 匿名（降级链）
- 脱敏应用点：档案卡片名、保存/载入/修改 toast、盘面结果头 person 行
- 搜索仍按真名（本地数据，方便本人检索）
- 隐私开关切换：即时重渲档案面板 + 结果头 person 行（若有）

### C3. 结果头 person 行
- 盘面结果头顶部新增 person 行：显示名 · 性别（无姓名/昵称且隐私开时不显示）
- 载入档案/切开关即时刷新（RENDER.renderHead 复用）

### C4. 档案字段模型（扩展，向后兼容）
```
{id, name, nickname?, yiming?, gender, mode, y, m, d, leap, scIdx, h, mi,
 prov, city, dist, lng, useSolar, advLateZi, note, createdAt, updatedAt}
```

## D. 验证要点
1. test=1 自检全绿（既有 40+ 断言不回归）
2. 主表单：小名/艺名输入 → 排盘 → 保存 → 档案卡片显示名 = 脱敏链结果
